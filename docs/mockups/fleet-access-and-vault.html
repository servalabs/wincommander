Vault — Owner and disk boundary

FieldNeedWhat to enter
Owner principalThe administrator that keeps Full access and receives every volume credential.Existing Windows username. Auto-filled from the current user, e.g. Parth.required
Mount scopeDocuments that a mount is private to that Windows session.Nothing. Locked to Per-user session isolation.read-only
Protected engine directoryWhere the VeraCrypt / WinCommander engine is installed.Default C:\Program Files\WinCommander\VeraCrypt Engine. Change only if installed elsewhere.required
Protected SYSTEM driver preloadLoads the driver at SYSTEM startup so standard users never get service-control or driver-load rights.Leave ON unless you are debugging driver load.default ON
Allow selected-disk unallocated spaceLets raw volumes allocate unused space on the pinned test disk only — never C: or D:.ON for raw/unallocated layouts. OFF to forbid that allocation path.default ON
Unallocated reserve (MiB)Keeps a slack amount unused after planned raw-volume allocations.Integer ≥ 0. Default 256. Disabled if the switch above is off.default 256
Discover test partitionsFinds eligible disks so C:/D: cannot be inferred from a letter.Click, then pick an eligible partition. This pins disk number + unique id. Required before Save.required
Selected diskThe pinned identity used by the manifest.Not typed. Shown after you pick a discovered partition. Confirmation token is stored automatically.derived

FieldNeedWhat to enter
Volume nameLabel in the permission matrix.e.g. Evidence or New volume.required
TypeHow the volume is backed.Container = file (.hc). Raw partition = device on the pinned disk. Decoy + hidden = outer + hidden volume.default Container
Backing path / deviceWhere bits live.Container filename such as evidence.hc, or \\.\HarddiskNPartitionM that belongs to the pinned disk.required
Size (MiB)Container / partition size.Number ≥ 64. Default 1024.required
Drive letterLetter used when mounted.One A–Z, unique across volumes, never C or D. Auto-picked from V, U, W…required
Credential referenceHandle for the password stored elsewhere. Not the password.e.g. Credential-evidence. Never paste a passphrase here.required
Hidden size (MiB)Inner volume size when Type is Decoy + hidden.Number ≥ 32. Default 128. Hidden when Type is not dual.dual only
Hidden credentialHandle for the hidden-volume password.Another non-secret reference. Hidden when Type is not dual.dual only

Group permissionWhat that Access-control group may do on this volume.No access, Read, or Read & write. If a user is in several groups, the highest wins.per group
