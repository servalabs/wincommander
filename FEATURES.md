# Features — WinCommander

> Complete, flat inventory of shipped capabilities. The code is the source of truth.
> Entry points cite the registering Tauri command, implementing Rust module, React
> panel, or encrypted PowerShell module. Paid commands route to the Pro sidecar
> over IPC; private implementation details are intentionally omitted.

## At a glance

- Type: Windows desktop app (Tauri v2)
- Platform: Windows 11 (`x86_64-pc-windows-msvc`); Administrator required for most operations
- Primary stack: Rust backend (`src-tauri/`), React 19 + TypeScript + shadcn/ui (Radix) + Tailwind 4 frontend (`src/`), AES-256-GCM-encrypted PowerShell 5/7 modules, optional Python 3.12 for local AI
- Shape: two binaries — `wincommander-free.exe` (open, AGPL) and `wincommander-pro.exe` (paid sidecar, Commercial) — plus `wincmd-shared` IPC types crate
- App version: see `package.json` / `src-tauri/commander-free/tauri.conf.json`

## Pro sidecar capabilities

> **Every row in this section is a Pro feature.** The capabilities below are implemented in the
> sibling Pro repo (the `commander-pro` crate). The Free binary ships only thin Tauri-command
> wrappers that call `license::require_paid` and forward to the Pro sidecar via
> `sidecar::dispatch_paid_command`; the heavy logic — TCP listeners, `netsh`/`cipher` shell-outs,
> classification heuristics, and ExifTool/WizTree CLI orchestration — run only inside Pro, as does
> the Deep-Clean / `Clear-*` destructive PowerShell. **One destructive exception stays in Free:** the
> panic self-destruct / Lockdown wipe (`backend.rs::lockdown`), gated on
> `settings.ideal.privacy.selfDestruct.enabled === true` (opt-in; refuses with an error if not set) —
> so this section's scope is the *paid*
> heavy logic, not an unqualified "no destructive PowerShell in Free" claim. Pro entry points cite the
> `feature_id` dispatch arm in `commander-pro/src/handlers.rs` or a dedicated Pro module.
>
> These rows are heuristic/behavioural detection and analysis features (recon, rogue-AP,
> metadata, disk classification), not an LLM, plus the MediaPipe Privacy Shield, which is Free with a quota.

## Competitive Position — vs the market (July 2026)

_Static competitive review. Competitor capabilities were profiled from public sources as of July 2026; re-verify before customer-facing use. The consumer myth-vs-reality items referenced below live in the Sovereignty Risk Matrix SSOT: `assets/components/risk-matrix/exposures.ts` (the `PERCEPTIONS` array)._

**Perceived-secure vs reality:** buyers assume "BitLocker is on, so I'm safe" and "delete/format wipes it" — both fail (default TPM-only BitLocker is bypassable without a PIN; an OS-level overwrite cannot sanitize an SSD). WinCommander's honest answers are TPM+PIN detection and crypto-erase, not a "7-pass wipe."

### Where WinCommander wins
- Only product in this set that puts filename search, content search, encryption orchestration (BitLocker + VeraCrypt), secure erase, network/behavioral monitoring (honeypot, Wi-Fi Guard), and duress/dead-man response in one console with a single measurable score — everyone else is a point tool.
- Self-hosted fleet server with no Azure AD / cloud dependency, unlike Intune, CrowdStrike, or Sophos, which are architecturally SaaS-first.
- Free tier is AGPL and source-auditable; CCleaner and O&O are closed-source with a documented supply-chain incident (CCleaner, 2017) that this design explicitly guards against (Defender-flaggable logic quarantined in a separately-gated paid sidecar).
- Honest about crypto-erase as the real guarantee rather than marketing an obsolete "7-pass wipe" the way several wipe utilities still do for SSD/NVMe media.
- The duress cascade (in-OS crypto-erase → reboot-to-USB firmware sanitize, fleet-triggerable) has no equivalent bundled anywhere in this comparison set — Absolute Persistence exists to defeat exactly this kind of wipe.
- Fleet-wide content search is implemented end to end over the self-hosted server, targeting the SMB gap below Tanium Reveal and dtSearch Network pricing.

### Where it loses / gaps vs competitors
- Semantic ("find by meaning") search is still planned, not shipped.
- No certified sanitization claim comparable to specialist ITAD products — hardware secure-erase is detection-only (probe), not an executed, audited sanitize.
- No forensic-grade eDiscovery features (dedup, near-dup clustering, legal hold, chain-of-custody export at Nuix/X1 depth) for litigation-scale review.
- Fleet-wide content search across many PCs is implemented; live Windows/server acceptance and release packaging remain the honest operational proof points.
- Not FIPS-140 validated (no CMVP certificate exists), so it cannot compete on that specific enterprise-procurement checkbox.
- No firmware-embedded persistence/asset-recovery play like Absolute — by design, since that's the opposite of the sovereignty thesis, but it is a real capability gap for buyers who also want theft-recovery tracking.

### The wedge
Nobody else bundles local-first content search + encryption orchestration + honest crypto-erase + duress/dead-man response + self-hosted fleet management in a single auditable console — competitors are either a single-purpose tool (Everything, Eraser, VeraCrypt) or an enterprise SaaS platform (Tanium, Intune, CrowdStrike) priced and architected for thousands of seats. The second wedge is structural: SMB-priced content search *across many PCs at once* is a category Tanium Reveal and dtSearch Network only serve at enterprise scale — WinCommander's fleet server already has the wire format reserved for it.

### How people actually do this today (and why they think they're safe)
Most Windows users rely on Windows Search for finding files, BitLocker's silent automatic device encryption (armed only if they signed in with a Microsoft account, with the recovery key escrowed to that same account) for "encryption," Shift-Delete or an empty Recycle Bin for "deleting" sensitive files, and nothing at all for endpoint posture or emergency response. They feel safe because the drive shows as encrypted and the file is "gone" — but the BitLocker key is recoverable by anyone with account or legal access to that Microsoft account, deleted files are trivially recoverable until overwritten, Windows Search rarely indexes file contents outside a few libraries, and there is no dead-man switch or duress response if the device is seized or coerced out of their hands.
